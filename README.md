# auth-lab

A hands-on project for understanding how authentication works by progressively building an educational authentication library.

Built with TypeScript and Vite+, using React as a minimal interactive playground and Hono to expose behavior through HTTP.

The [roadmap](roadmap.md) covers password authentication, sessions, authorization, tokens, OAuth, and OpenID Connect through small implementations and experiments.

The goal is to understand the mechanisms and their trade-offs, rather than build a production-ready authentication library.
